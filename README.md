# Krishi Shayak (कृषि सहायक)

AI-powered assistant for farmers and Indian kirana stores — crop advice, disease detection, weather, mandi prices, government schemes, and store management, all in one app.

## Features

- **Shopkeeper mode** — dashboard, udhaar (credit) tracker, menu manager, bill generator with WhatsApp/PDF export, fake payment detector, analytics
- **Customer mode** — store discovery, browsing, cart, order placement with WhatsApp confirmation
- **Farming tools** — crop suggestions, disease detection, weather, mandi prices, farm calendar
- Hinglish-first UI, mobile-first design, dark mode support

## Tech Stack

React + TypeScript + Tailwind CSS + shadcn/ui. No backend required — data persists via localStorage.

## Development

You'll need [Node.js](https://nodejs.org) and npm (install via [nvm](https://github.com/nvm-sh/nvm) if needed).

```bash
git clone <https://github.com/Mridulnigam24/Krishi-Sahayak>
cd <repository-name>
npm i
npm run dev
```
